# Contributing

1. Update the relevant domain file under `docs/`.
2. Update `src/full-map.md` when the hierarchy changes.
3. Keep references at approximately `name -> one-line organizational purpose` depth.
4. Give each reference one primary home; avoid duplication unless a cross-reference is explicitly useful.
5. Group standards/frameworks primarily by function and laws/regulations primarily by jurisdiction.
6. Verify current versions and claims against an authoritative issuer or regulator.
7. Update `CHANGELOG.md` for material changes.
