# Contributing

1. Create a branch from `main`.
2. Update the relevant file under `docs/`.
3. Update `src/full-map.md` when the hierarchy changes.
4. Verify that the domain Mermaid map renders on GitHub.
5. Record material changes in `CHANGELOG.md`.
6. Cite an official issuer such as ISO, IEC, NIST, ENISA, the European Commission, AICPA, or the relevant regulator in the pull request.

Use the pattern:

```text
Domain
└── Standard / Framework / Regulation
    └── Short organizational purpose
```

Keep each domain Mermaid diagram small enough to remain readable on GitHub.
