# Contributing

## Proposing a change

1. Create a branch from `main`.
2. Edit `cybersecurity-grc-map.md`.
3. Verify that the Mermaid block renders correctly.
4. Add the change to `CHANGELOG.md`.
5. Open a pull request with an official reference supporting the update.

## Content conventions

```text
Domain
└── Standard / Framework / Regulation
    └── Short organizational purpose
        └── Optional component
```

- Prefer official names and current versions.
- Keep each node concise.
- Use acronyms only when they are widely recognized or expanded nearby.
- Put cloud-specific guidance under Cloud Security.
- Put supplier and supply-chain requirements under Supplier, Third-Party and Supply Chain Security.
- Put product evaluation schemes under Assurance, Audit and Security Evaluation.
- Put privacy regulations under Privacy Management or Sector and Regional Regulations according to scope.
